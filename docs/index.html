Features

Everything an art pipeline needs.
Nothing it doesn’t.

✦

Style bible & pillars

Reference images and rules stack per folder, so characters, items and UI each keep their own look.

▤

Your project is just folders

Sections, pages and assets are Markdown files. Readable, diffable, yours.

◎

See the prompt before you pay

Model, price, final prompt and every attached image — editable before each run.

⚙

Bring any model

Anthropic, OpenAI, Gemini, OpenRouter, Ollama, LM Studio or any OpenAI-compatible URL.

›_

Manual, 2D or full auto

Per project: Glob only writes the prompts and asks, makes 2D right away, or goes all the way to the 3D model. A spend cap keeps it honest.

♪

Sounds, music & voices

Sound effects in up to 6 takes, music and voice lines. Trim on the waveform and check a loop by ear.

▦

Board & press kit

Every asset on one canvas, a 3D lineup at game scale, and a press-kit page you can upload to itch.io.

⌘

Fast to drive

Pick winners with 1–9 and Enter, jump anywhere with ⌘K, and generate every missing asset in one go.

⌂

Local & private

Runs on 127.0.0.1. Keys stay in ~/.forge, never in a project or export. Demo Mode costs nothing.

For your coding agent

Say “open Glob”.
No more placeholder cubes.

Plug in the agent you already use: Claude Code, Codex, Gemini CLI, OpenCode, Cursor or any MCP client. One glob connect in your game folder sets it up. Then tell it to open Glob and the studio pops up in your browser, right on your game.

  • Your agent starts Glob on localhost when you ask, or the moment it orders its first asset.
  • Orders, not prompts: the agent writes a brief and keeps its placeholder until the asset is ready.
  • You choose how far Glob goes: just the prompts, 2D right away, or the full 3D model, with a spend cap.
  • SHA-256 receipts in glob_delivery/manifest.json; Glob never writes anywhere else.

Get started

Free. Open source.
Forging in a minute.

Glob costs nothing and the code is MIT-licensed. You only bring API keys for the image and 3D providers you use (Gemini, Meshy, ElevenLabs) and pay them directly. No keys yet? Demo Mode is free.

The easy way: paste this into your coding agent

Set up Glob for this game: read https://soulnassim.github.io/Glob-Game-Forge/agent.md

Run it from your game's folder.
Or do it yourself
>irm https://raw.githubusercontent.com/SoulNassim/Glob-Game-Forge/main/scripts/install.ps1 | iex
$curl -LsSf https://raw.githubusercontent.com/SoulNassim/Glob-Game-Forge/main/scripts/install.sh | sh
$git clone https://github.com/SoulNassim/Glob-Game-Forge && cd Glob-Game-Forge && uv run forge

The one-liners install uv if needed, then Glob. Then, in a new terminal in your game folder, run glob connect: it connects your coding agents and opens Glob in your browser.

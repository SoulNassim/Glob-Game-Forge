# Roguelike run structure

- A run is 3 waves across 3 districts, then a boss invader.
- After each wave the player picks one perk card from three options.
- Perks stack: tail-whip reach, stomp shockwave, breath colour bands, extra hearts.
- A failed run keeps coins and unlocks one new perk for the pool.
- Seeds are shown on the result screen so runs can be shared.

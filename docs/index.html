For your coding agent

No more placeholder cubes.

Plug in the agent you already use: Claude Code, Codex, Gemini CLI, OpenCode or any MCP client. It asks Glob for an asset instead of faking one; Glob forges it, delivers it into the game and writes a receipt.

  • Requirements as a checklist — one Markdown line per asset, ticked when delivered.
  • SHA-256 receipts in DELIVERY_MANIFEST.json.
  • Preview before writing into a Godot, Unity or Unreal project.

Forging in a minute.

Glob costs nothing and the code is MIT-licensed. You only bring API keys for the image and 3D providers you use (Gemini, Meshy, ElevenLabs) and pay them directly. No keys yet? Demo Mode is free.

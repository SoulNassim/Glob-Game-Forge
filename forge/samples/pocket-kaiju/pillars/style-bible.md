# Style bible

- Look: rendered 3D game asset (toon / cel-shaded), like a model in the game engine, not a flat 2D drawing
- Chunky toy-like proportions with soft rounded edges, like vinyl collectible toys
- Candy pastel base colors with neon magenta and cyan accents
- Single subject centered on a plain background
- 3/4 front view, soft studio lighting
- Game-ready, under 15k triangles

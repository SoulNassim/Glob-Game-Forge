# Core loop

1. Spawn on a neon block of the miniature city.
2. Waves of tin-toy invaders march in from the edges.
3. Stomp invaders, tail-whip groups, charge the rainbow atomic breath.
4. Smash props for coins, health and perk tokens.
5. Clear the wave to unlock the next district, or fall and start over.

## Feel targets

- Hits should be juicy: hit-stop, squash and stretch, sparkle bursts.
- Every prop should feel like a chunky toy that gives way when hit.
- Runs stay short: a full run ends in about 3 minutes.
